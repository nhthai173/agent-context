# Tone: correspondence (email, chat message, note to a colleague)

**Reader:** a colleague or client skimming on a phone. **Goal:** understand and act quickly.

- First line states what you need from them or the outcome; no long greeting.
- If context is shared, do not restate the problem; give the decision first, the necessary reason after.
- One topic per message; several requests get numbers.
- Natural tone, polite enough; keep address forms consistent with the recipient (in Vietnamese: anh/chị/bạn).
- Avoid chatbot closers ("I hope this helps", "Let me know if you need anything else") unless genuinely needed.
- Give a deadline and a point of contact when relevant.

Before/after:
- Before: "I would like to share some information regarding the deployment schedule, hoping it will be helpful."
- After: "Deployment is set for Thursday Nov 14. Please confirm port 8333 is open on the server by Wednesday."
