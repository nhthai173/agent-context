# Natural phrasing and terminology (all tones)

## Why a sentence sounds unnatural
- **Word-for-word translation.** Translate the meaning, not the words. Language-specific examples: `vietnamese.md`.
- **Too many nominalizations** ("carrying out the performing of the check"): turn them back into verbs.
- **Stacked passives** ("is ... is ..."): use the active voice when the actor is clear.
- **Contrasts of unlike things:** both sides of a contrast must be the same kind of item.
- **Colloquial wording in formal text**, or stiff wording in a message: match the tone file.

## Terminology
1. Pick one name per concept and record it in the project's glossary.
2. When a term changes, grep the whole file for the old one and replace every occurrence; report how many were replaced.
3. Identifiers (file, function, variable, environment variable, endpoint) stay verbatim in backticks. Do not mix whole sentences of another language into the text.
4. If the code uses several names for one concept (for example carrier, pod, load), ask the user to choose one for the whole document.
